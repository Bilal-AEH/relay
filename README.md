# relay

Les humains ont toujours eu besoin de faire circuler l'information, d'établir la confiance, de contrôler l'accès, de survivre à la perte d'un membre clé.

Les réseaux informatiques résolvent exactement les mêmes problèmes — avec d'autres outils, dans d'autres délais, pour d'autres raisons.

Ce projet trace ce fil. Pas comme une métaphore. Comme une démonstration.

## Organisation

```
sessions/   une exploration par concept — la psyché d'abord, le protocole ensuite
docs/       référence technique par sujet
```

## Stack

```
Python 3 — socket, ssl, struct
Wireshark — captures et analyse
```
